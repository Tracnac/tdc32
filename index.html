TDC32.01 Virtual Computer

Boot ROM · system page · keyboard · VBL/IRQ · monochrome framebuffer

Program

One instruction per line. Labels use :name; comments start with ;. Numbers are decimal, $ hexadecimal, or % binary; prefixes work in instructions and directives.

Instructions include integer and floating-point operations, conditional branches, BSR/RTS/RTI, SWI, PUSH, and POP. Pseudo-ops are INC and DEC.

Set addresses with .adr address; declare code/data labels with .code name and .data name. Initialize data with .str "ASCII", .u8, .u16, and .u32.

Reset boots a small ROM stub, which launches the assembled program in user mode at RAM entry $00000400. System page: vectors $0000–$00FF, stack/boot registers $0100–$0113, system RAM $0114–$01FF, I/O board $0200–$02FF. Keyboard input: arrows or A/D, Space to fire, Enter to start, Escape to pause. Framebuffer: $00010000; VBL ticks every 16,667 emulated instructions. Load examples/io-board-test.asm to test keyboard and frame polling.

Ready. Reset / Assemble to assemble the source.
