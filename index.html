TDC32.01 — architectural emulator

Minimal CPU POC · 16 registers · 32-bit words · POC counts one cycle per instruction

Program

Ready. Reset / Load to assemble the source.
Syntax: one instruction per line; labels use :name. Supports integer and floating-point instructions, LI/LEA/ABS/MIN/MAX/NEG/NOT/INC/DEC/BTST/BSET/BCLR/BCHG aliases, `.adr`, `.code`, `.data`, `.str`/`.u8`/`.u16`/`.u32`, BPR, B[condition], JSR/RTS/RTI, SWI, and SP stack forms. The POC video buffer is at 0x00010000 and is an emulator-only memory-mapped region. The POC has no ROM image; vector/service entry stops after saving the exception frame. Comments start with ;.
